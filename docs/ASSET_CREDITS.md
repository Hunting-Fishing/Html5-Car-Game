## Approved External Asset Sources

### Kenney

Use only packs with clear CC0/public-domain license notes from Kenney. Store downloaded files under:

```text
public/assets/vendor/kenney/
```

### Game-icons.net

May be used for generic SVG icons. Attribution is required. Store under:

```text
public/assets/vendor/game-icons/
```

Add specific icon names and authors here when used.

### OpenGameArt

May be used only when each asset license is checked. Store under:

```text
public/assets/vendor/opengameart/
```

Add the asset URL, author, and license here before shipping.

## Prohibited Assets

Do not add:

- real car manufacturer logos
- copied screenshots from other games
- Fallout Shelter assets
- JILI Idle Auto Shop assets
- Idle Car Repair assets
- Idle Workshop Tycoon assets
- TapTap game screenshots/assets
- Ludos Labs game screenshots/assets
- branded tool logos
- unlicensed paid marketplace assets
