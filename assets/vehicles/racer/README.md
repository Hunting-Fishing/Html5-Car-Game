# Racer Vehicle Asset Replacement Guide

Replace these placeholder SVG files with your final vehicle artwork.

## Preferred final format

```text
PNG
1024 x 512 px
transparent background
side-view vehicle
front faces right
wheels visible
no manufacturer logos
no text baked into the car image
under 500 KB when possible
```

SVG also works. The placeholders are SVG so the files are easy to swap now.

starter-hatchback.svg
