Race visual override assets
===========================

These files are wired into the Race/Pixi and Road Runner canvases. Replace them with final PNG/WebP/SVG art using the same filenames to reskin the mode without touching code.

- `routes/street.svg`
- `routes/delivery.svg`
- `routes/economy.svg`
- `routes/rough.svg`
- `routes/showcase.svg`
- `routes/track.svg`
- `routes/barangay.svg`
- `routes/farm.svg`
- `routes/mountain.svg`
- `routes/port.svg`

Recommended size: 900x520 or wider. Keep the lower third mostly open so the road, car, rewards, and warnings remain readable.
