# Lines Mode Asset Overrides

Drop replacement UI art for Lines mode into this folder. Keep the same filenames and the game will pick them up without code changes.

Recommended sizes:

- `icons/*.svg` or PNG: square, 128x128 or larger.
- `gui/panel-frame.svg`: wide panel frame, 960x240 style works well.
- `gui/line-card.svg`: card backing, 900x260 style works well.
- `gui/progress-track.svg` and `gui/progress-fill.svg`: horizontal bars.
- `gui/*-button.svg`: wide button art, 360x120 style works well.
- `badges/*.svg`: small status badges, 180x72 style works well.
