# Git Setup

Run this inside the project folder:

```bash
git init
git add .
git commit -m "Initial 365 Micro Garage companion V9"
```

Then create a GitHub repo and connect it:

```bash
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/365-micro-garage.git
git push -u origin main
```
